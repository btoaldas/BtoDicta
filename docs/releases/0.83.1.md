# BtoDicta 0.83.1

El pulido con IA deja de quedarse esperando cuando un proveedor no contesta.

- La espera base del pulido se puede bajar hasta 3 s y crece con el largo del
  texto según tiempos medidos, en vez de un margen de minutos. La cascada entera
  se rinde a los 12 s en un texto corto y entrega el original.
- Z.ai (GLM) responde sin razonamiento previo, que le hacía agotar el plazo.
- Gemini usa `gemini-3.5-flash-lite`; `gemini-2.5-flash` fue retirado para
  cuentas nuevas.

Paquete para macOS 14 o posterior y Apple Silicon. El DMG conserva la identidad
de firma y lleva firma Ed25519 para la actualización automática.
