# BtoDicta 0.83.3

BtoDicta deja de calentar la Mac después de dictar con texto en vivo local.

- Cada dictado con Voxtral Realtime o Nemotron en vivo dejaba, al cerrarse el
  motor, un lector de su salida de errores llamándose sin fin. Se acumulaban
  dictado tras dictado: macOS registró la app en 77–86 % de CPU sostenido y solo
  reiniciarla lo calmaba. Ahora el lector se apaga al terminar el motor.
- El mismo cierre se aplicó a la salida normal del motor en vivo y a la voz XTTS
  en streaming, que tenían el mismo patrón.

Paquete para macOS 14 o posterior y Apple Silicon. El DMG conserva la identidad
de firma y lleva firma Ed25519 para la actualización automática.
