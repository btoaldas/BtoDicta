# BtoDicta 0.83.2

El pulido con IA deja de contestar o rechazar lo que dictas.

- Un dictado con forma de pedido («dame un resumen de lo que se hizo aquí») podía
  volver como «Lo siento, pero no puedo ayudar con eso.»: el modelo lo tomaba como
  un encargo para él. Ahora las instrucciones aclaran que el dictado nunca es un
  pedido para la IA.
- Si aun así la respuesta trae una negativa nueva o no conserva al menos el 40 %
  de las palabras del dictado, se descarta, se prueba el siguiente proveedor y,
  en último caso, se entrega el texto original.

Paquete para macOS 14 o posterior y Apple Silicon. El DMG conserva la identidad
de firma y lleva firma Ed25519 para la actualización automática.
