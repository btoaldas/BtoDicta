# BtoDicta 0.83.5

La voz XTTS en streaming ya no deja procesos de voz trabajando en segundo plano.

- Si una frase nueva empezaba mientras otra seguía en marcha, el proceso de la
  primera quedaba vivo con el modelo de voz en memoria. Ahora la frase nueva corta
  la anterior, igual que el botón Cancelar.

Paquete para macOS 14 o posterior y Apple Silicon. El DMG conserva la identidad
de firma y lleva firma Ed25519 para la actualización automática.
