# BtoDicta 0.84.0

Frases comunes con tu voz, también sin internet.

- Las frases fijas que BtoDicta dice a menudo (por ejemplo «Resumen del día. No
  tienes tareas pendientes.») se generan una vez con tu voz de ElevenLabs y el
  modelo eleven_v4 con expresiones, y se guardan en la Mac.
- Después suenan desde disco: sin red, sin gastar créditos y sin caer a la voz de
  macOS. Al arrancar con red solo se generan las que falten.
- Se desactiva con `tts_frases_cache` en `config.json`. No se usa si elegiste la voz
  de macOS o un clon local.
