# BtoDicta 0.83.4

La voz XTTS en streaming ya no corta el final de la frase.

- Si el motor de voz terminaba antes de que BtoDicta leyera sus últimos trozos
  de audio, esos trozos se perdían. Ahora la frase se da por hablada solo cuando
  se leyó todo el audio y el motor terminó.

Paquete para macOS 14 o posterior y Apple Silicon. El DMG conserva la identidad
de firma y lleva firma Ed25519 para la actualización automática.
